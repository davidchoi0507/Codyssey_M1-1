# 🎙️ 현대 전기 녹음 100년사(1926~2025) 대중음악 시계열 트렌드 분석 프로젝트
**"마이크의 탄생(3분) ➔ 비틀즈와 핑크 플로이드(5분대 정점) ➔ 숏폼 스트리밍 완결(3분 원점 회귀)"**

본 프로젝트는 1926년 인류 전기 마이크 녹음(Electrical Recording) 상용화 원년부터 2025년 숏폼 완결기까지, 100년간 발매된 17만 건의 대규모 음원 아카이브 데이터를 바탕으로 녹음 저장 매체와 플랫폼 비즈니스 모델이 대중음악의 곡 길이와 사운드 특성에 미친 역사적 순환 궤적을 실증하고 2030년까지의 미래 추세를 예측합니다.

## 🚀 실행 방법 (Execution Guide)

### 방법 A. Python 스크립트 실행 (CLI 자동화 파이프라인)
100년(1926~2025) 데이터 정제, 이상치 필터링, 연쇄 지수 보정, 고해상도 차트 생성을 원클릭으로 수행합니다.
```bash
python analysis.py
```

### 방법 B. 주피터 노트북 실행 (`analysis.ipynb`)
주피터 랩 또는 노트북 환경에서 100년 분석 결과와 차트를 인터랙티브하게 확인합니다.
```bash
jupyter notebook analysis.ipynb
```

### 방법 C. [보너스 과제 1] Streamlit 인터랙티브 대시보드 실행
Plotly 인터랙티브 엔진 기반으로 **다크 모드/라이트 모드 자동 동기화**, **마우스 호버 실시간 상세 툴팁**(연도, 초, 분, 역사적 사건), **줌인/줌아웃/팬 조작**, **인터랙티브 데이터 정렬 및 CSV 다운로드**를 지원합니다.
```bash
streamlit run app.py
```
* 브라우저에서 `http://localhost:8501`로 자동 연결됩니다.

## 📊 주요 분석 결과 요약
* **100년 곡 길이 거대 순환**: 1926년 마이크 녹음 탄생 당시의 3분 한계(170.4초)에서 시작하여, 1976년 핑크 플로이드 앨범 록 전성기에 **4분 26초(266.4초)로 역사상 최고점**에 도달한 후, 2025년 숏폼/스트리밍 완결로 인해 **100년 전 마이크 녹음 원년 시절의 3분대(188.4초, 3분 8초)로 완벽히 원점 회귀**
* **아티스트 극적 대비**: 라디오 팝의 비틀즈(평균 174.4초, 2분 54초) vs 프로그레시브 록의 핑크 플로이드(평균 313.9초, 5분 14초)의 140초(2분 20초) 격차 확인
* **미래 예측 (2026~2030)**: 현재 시점(2026년 9월, 약 184.8초)을 지나 2030년 대중음악 길이는 **약 170.8초(2분 51초)**로 수렴할 것으로 전망되며, 2분 30초가 물리적 하한선(Floor limit)이 됨
